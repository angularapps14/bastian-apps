Política de privacidad de
Adivina Quién Bíblico

Última actualización: 3 de septiembre de 2026

Esta Política de Privacidad explica cómo Adivina Quién Bíblico, un juego de charadas bíblicas desarrollado por Angular Apps para jugar en familia o por equipos, trata la información en su versión actual.

1. Información general

La aplicación no requiere crear una cuenta, iniciar sesión ni proporcionar nombre, correo electrónico, número de teléfono u otra información personal para jugar. No incorpora un sistema de cuentas remotas ni un backend propio.

2. Datos almacenados localmente

La aplicación puede guardar localmente en el dispositivo preferencias del método de control, sensibilidad, vibración, estado del tutorial, preferencia de instrucciones previas, historial reciente de tarjetas, ajustes, progreso o resultados locales cuando corresponda.

Las partidas por equipos pueden utilizar nombres de equipos, puntuaciones, rondas y resultados para administrar la partida. Estos datos se utilizan localmente y no se envían a servidores de Angular Apps.

3. Sensor de movimiento

Cuando se utiliza el control por inclinación, Adivina Quién Bíblico accede a los sensores de movimiento del dispositivo para detectar los gestos necesarios para jugar. Las lecturas se procesan localmente, se utilizan únicamente para interpretar la inclinación, no se usan para identificar al usuario, no se guardan como historial personal y no se transmiten a servidores de Angular Apps. El usuario puede seleccionar el método de control mediante botones.

4. Contenido y resultados de juego

Los aciertos, tarjetas pasadas, puntuaciones, rondas y resultados se utilizan para proporcionar las funciones del juego y mostrar los resultados correspondientes. La versión actual no sincroniza este contenido con una cuenta en Internet.

5. Aplicaciones recomendadas y enlaces externos

La pantalla principal puede mostrar aplicaciones recomendadas de Angular Apps. Cuando el usuario toca voluntariamente una de estas recomendaciones, puede abrirse la ficha correspondiente en Google Play. Una vez que el usuario abandona Adivina Quién Bíblico, se aplican las políticas del servicio externo correspondiente.

6. Publicidad, analítica e Internet

La versión actual de Adivina Quién Bíblico no incorpora SDK de publicidad, AdMob, analítica de terceros, Firebase Analytics, cuentas, inicio de sesión ni un backend propio de recopilación de datos. Angular Apps no vende información personal mediante las funciones actuales de esta aplicación.

7. Conservación y eliminación

Los datos locales permanecen en el dispositivo mientras la aplicación conserve sus datos. El usuario puede eliminarlos borrando los datos de la aplicación desde los ajustes del sistema operativo o desinstalando la aplicación.

Como no existe una cuenta remota, no hay una cuenta online que eliminar ni una copia de progreso almacenada por Angular Apps en un servidor propio.

8. Seguridad

La información local utiliza los mecanismos de almacenamiento disponibles en el dispositivo. Se recomienda mantener actualizado el sistema operativo y utilizar las funciones de bloqueo y seguridad del dispositivo. Ningún método de almacenamiento puede garantizar seguridad absoluta.

9. Privacidad de menores

La aplicación está diseñada como un juego familiar y no solicita cuentas ni recopila intencionalmente información personal de menores mediante sus funciones actuales. Las declaraciones de audiencia, clasificación y contenido se realizan de forma separada en Google Play.

10. Cambios

La política puede actualizarse cuando cambien las funciones, los SDK, los servicios de terceros o las prácticas de privacidad. La fecha de actualización debe aparecer al inicio.

11. Contacto

Para consultas relacionadas con privacidad, escribe a angular.apps14@gmail.com.
