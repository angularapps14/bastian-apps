Política de privacidad de
Bloques: Puzzle y Biblia.

Última actualización: 29 de agosto de 2026

Esta Política de Privacidad explica cómo la versión actual de Bloques: Puzzle y Biblia trata la información al jugar. Es un juego de bloques con preguntas y curiosidades bíblicas que funciona principalmente de forma local en el dispositivo.

1. Cuenta y datos personales

La aplicación no requiere crear una cuenta, iniciar sesión, proporcionar correo electrónico ni crear un perfil en línea para jugar. No solicita al usuario que introduzca datos personales como parte de sus funciones normales.

2. Datos guardados localmente

Para que el juego pueda conservar el progreso, la aplicación guarda datos localmente mediante el almacenamiento de preferencias del dispositivo. Esto puede incluir la mejor puntuación, la partida y el tablero activos, estadísticas, configuración, avance del tutorial, curiosidades desbloqueadas, colección e historial reciente usado para evitar repeticiones de contenido. Si el usuario activa los recordatorios, también se guarda localmente su preferencia de notificaciones y la última apertura necesaria para calcular periodos de inactividad.

Estos datos se usan para proporcionar las funciones del juego y no requieren una cuenta. El código actual no incorpora sincronización ni un servidor propio para estas funciones. La conservación final de los datos también puede depender de las copias de seguridad o ajustes del sistema operativo que el usuario tenga habilitados.

3. Contenido bíblico

Las preguntas, desafíos y curiosidades bíblicas forman parte del contenido educativo local de la aplicación. Ese contenido no constituye recopilación de datos personales del usuario.

4. Publicidad, analítica y servidores

La versión actual no incorpora Google AdMob, otros SDK de publicidad, Firebase Analytics, Google Analytics, servicios de inicio de sesión ni analítica de usuarios. Tampoco se identificó un backend o servidor propio al que el juego envíe el progreso.

5. Notificaciones locales

La aplicación puede solicitar el permiso de notificaciones para mostrar recordatorios locales después de periodos de inactividad. Estos recordatorios se programan en el dispositivo, no requieren cuenta, no usan un servidor propio y no se utilizan para publicidad. El usuario puede desactivarlos desde Configuración dentro de la aplicación o desde los Ajustes de Android.

6. Enlaces a servicios externos

La sección Aplicaciones recomendadas permite abrir voluntariamente las fichas de Hábitos Cristianos y Mi Tiempo de Oración en Google Play. Al abrir uno de estos enlaces, el usuario abandona la aplicación y pueden aplicarse las políticas de privacidad de Google Play, Google u otro servicio externo que gestione el enlace. Bloques: Puzzle y Biblia no controla esos servicios externos.

7. Permisos

La aplicación no solicita permisos sensibles como cámara, micrófono, ubicación, contactos, teléfono ni acceso a archivos personales. La versión release puede solicitar el permiso de notificaciones únicamente si el usuario el activa desde el menú. No requiere permisos sensibles para jugar.

8. Seguridad

El progreso se mantiene mediante el almacenamiento local del dispositivo. Ningún método de almacenamiento puede garantizar seguridad absoluta; recomendamos proteger el dispositivo con las opciones de bloqueo y seguridad que ofrece el sistema operativo.

9. Menores

La aplicación no solicita cuentas ni recopila intencionalmente información personal de menores. La definición de audiencia y las declaraciones aplicables se revisarán manualmente en Google Play Console según la configuración de publicación.

10. Cambios en esta política

Esta política puede actualizarse si cambian las funciones de la aplicación, los servicios externos o las prácticas de privacidad. La fecha de última actualización se mostrará al comienzo de esta página.

11. Contacto

Para consultas relacionadas con esta política, escribe a angular.apps14@gmail.com.
