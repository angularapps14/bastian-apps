POLÍTICA DE PRIVACIDAD DE
DESAFÍO DEL MENSAJE

Última actualización: 4 de agosto de 2026

1. Responsable y contacto

Desafío del Mensaje es una aplicación desarrollada por Angular Apps.

Para consultas relacionadas con esta política o con la privacidad de la aplicación, puedes escribir a:

angular.apps14@gmail.com

2. Alcance de esta política

Esta política explica cómo Desafío del Mensaje maneja la información generada durante el uso de la aplicación.

La aplicación funciona principalmente de manera local y no requiere crear una cuenta, iniciar sesión ni proporcionar información personal.

3. Datos personales

Desafío del Mensaje no solicita ni recopila datos personales como:

  • nombre;
  • dirección;
  • número telefónico;
  • correo electrónico;
  • ubicación;
  • contactos;
  • fotografías;
  • archivos personales;
  • información financiera;
  • identificadores publicitarios.

La aplicación no crea perfiles de usuario y no permite crear cuentas.

4. Información almacenada localmente

Para que la aplicación recuerde el avance del usuario, se guardan únicamente en el dispositivo datos relacionados con su uso, tales como:

  • progreso dentro de las categorías;
  • preguntas respondidas;
  • respuestas correctas e incorrectas;
  • preguntas que necesitan repaso;
  • pistas utilizadas;
  • introducciones ya vistas;
  • vidas disponibles;
  • preferencias de la aplicación;
  • estado y horario del recordatorio diario.

Esta información se almacena localmente en el dispositivo y no se envía al desarrollador ni a servidores externos.

5. Recordatorios y notificaciones

La aplicación permite configurar voluntariamente un recordatorio diario.

Cuando el usuario activa esta función, la aplicación puede solicitar permiso para mostrar notificaciones.

Los permisos relacionados con notificaciones se utilizan solamente para:

  • mostrar el recordatorio elegido por el usuario;
  • mantener o restaurar el recordatorio después de reiniciar el dispositivo mediante el permiso RECEIVE_BOOT_COMPLETED;
  • utilizar sonido o vibración cuando corresponda.

El usuario puede desactivar el recordatorio desde la configuración de la aplicación o revocar el permiso de notificaciones desde los ajustes de Android.

La hora y el estado del recordatorio permanecen almacenados localmente.

6. Publicidad, analítica y seguimiento

Esta versión de Desafío del Mensaje:

  • no contiene anuncios;
  • no utiliza identificadores publicitarios;
  • no utiliza servicios de analítica;
  • no utiliza sistemas de seguimiento;
  • no vende información;
  • no comparte información personal con terceros.

7. Conexión a Internet y servidores

La aplicación no necesita una conexión a Internet para acceder a sus preguntas, categorías, progreso o recordatorios.

El contenido y los datos de progreso se procesan localmente en el dispositivo.

8. Compartición de datos

Desafío del Mensaje no transmite, vende, alquila ni comparte los datos locales del usuario con el desarrollador, anunciantes u otras empresas.

9. Conservación de la información

El progreso, las preferencias y los recordatorios se conservan localmente mientras la aplicación permanezca instalada y sus datos no sean eliminados.

Algunas categorías pueden reiniciarse desde la propia aplicación.

El usuario también puede eliminar todos los datos locales mediante cualquiera de estas acciones:

  • borrar los datos de Desafío del Mensaje desde los ajustes de Android;
  • desinstalar la aplicación.

Debido a que no existen cuentas ni servidores propios, el desarrollador no conserva una copia externa de estos datos.

10. Seguridad

La información de uso permanece dentro del almacenamiento privado asignado a la aplicación por Android.

La aplicación procura reducir al mínimo los permisos utilizados y no transmite el progreso del usuario por Internet.

Ningún sistema de almacenamiento puede garantizar seguridad absoluta, pero la aplicación limita el tratamiento de información al funcionamiento local necesario.

11. Privacidad de menores

La aplicación no solicita conscientemente información personal a niños, adolescentes ni adultos.

El funcionamiento es el mismo para todos los usuarios y el progreso permanece almacenado localmente.

12. Servicios de terceros

La aplicación utiliza componentes técnicos de Flutter, Android y bibliotecas necesarias para guardar preferencias y mostrar notificaciones locales.

Estos componentes se utilizan para el funcionamiento de la aplicación y no se integran servicios de publicidad, analítica ni seguimiento.

13. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones de la aplicación, los permisos utilizados o los requisitos legales y de las tiendas de aplicaciones.

La fecha de la última actualización aparecerá al comienzo de este documento.

Las modificaciones importantes deberán reflejarse tanto dentro de la aplicación como en la versión pública de esta política.

14. Contacto

Para realizar preguntas, informar un problema relacionado con la privacidad o solicitar información adicional, escribe a:

angular.apps14@gmail.com
