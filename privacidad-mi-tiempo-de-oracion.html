Política de privacidad de
Mi Tiempo de Oración.

Última actualización: 17 de julio de 2026

Mi Tiempo de Oración es una aplicación desarrollada por Angular Apps para ayudar a organizar y registrar la vida de oración. Esta política explica cómo trata la información la versión actual de la aplicación.

1. Información que no solicitamos

La aplicación no requiere crear una cuenta, iniciar sesión ni proporcionar correo electrónico o número telefónico. Tampoco envía los registros de oración a servidores propios de Angular Apps.

La aplicación sí permite que el usuario escriba voluntariamente nombres de personas y otros contenidos de oración para su propio registro local.

2. Datos guardados en el dispositivo

Mi Tiempo de Oración puede guardar localmente en el dispositivo:

  • personas por quienes el usuario desea orar y los motivos asociados;
  • peticiones de oración, sus descripciones, fechas y estados;
  • sesiones de oración, su duración, fecha, personas y peticiones seleccionadas, y notas asociadas;
  • testimonios y sus referencias vinculadas;
  • recordatorios, horarios, días, mensajes y estado de activación;
  • objetivo diario de oración y preferencia de apariencia;
  • datos usados en el propio dispositivo para calcular estadísticas, rachas, progreso y logros.

Estos datos pueden contener información personal, espiritual o religiosa que el usuario escriba voluntariamente. Según el código actual, se almacenan mediante el mecanismo local de preferencias de la aplicación y no se envían a servidores de Angular Apps. Las estadísticas y los logros se calculan localmente a partir de esos datos.

3. Notificaciones locales y permisos

La aplicación puede solicitar permiso para mostrar recordatorios de oración. Los recordatorios se programan localmente y el usuario decide si concede el permiso; puede desactivarlos desde la aplicación o desde la configuración del dispositivo.

En Android, la versión actual declara los permisos POST_NOTIFICATIONS y RECEIVE_BOOT_COMPLETED. El segundo permite restaurar los recordatorios programados después de reiniciar o actualizar el dispositivo. La aplicación no utiliza las notificaciones para leer mensajes ni para acceder al contenido de otras aplicaciones.

4. Servicios de terceros

La versión actual no utiliza Firebase, Google Analytics, AdMob, servicios de inicio de sesión ni almacenamiento en la nube. Tampoco incorpora servicios de publicidad, analítica o identificación de usuarios.

Si en una versión futura se incorporan servicios de publicidad, analítica o almacenamiento en línea, esta política será actualizada antes de su implementación.

5. Conexión a Internet

La versión actual puede utilizarse sin conexión: el código de la aplicación no realiza llamadas HTTP ni conexiones a servidores, y la configuración principal de Android no declara permiso de Internet para la versión de publicación.

Apagar Internet o activar el modo avión puede ser una recomendación de concentración durante la oración. La aplicación no modifica por sí sola la conectividad del dispositivo.

6. Uso y venta de datos

Angular Apps no vende los textos de oración, no comercializa las peticiones, no utiliza los testimonios para publicidad propia y no accede remotamente al contenido almacenado de forma local.

7. Conservación y eliminación

Los datos permanecen en el dispositivo hasta que el usuario borra los datos de la aplicación desde la configuración del dispositivo o desinstala la aplicación. La versión actual no incorpora copia de seguridad, sincronización ni recuperación remota; por ello, borrar los datos o desinstalar la aplicación puede eliminar permanentemente la información local.

8. Seguridad

La aplicación mantiene los datos en el dispositivo y limita su tratamiento a las funciones locales descritas. No se encontró un sistema de cifrado adicional implementado explícitamente para estos registros.

Ningún sistema de almacenamiento puede garantizar seguridad absoluta. Recomendamos proteger el dispositivo con las medidas de seguridad que ofrezca el sistema operativo.

9. Privacidad de menores

La aplicación no está diseñada para recopilar intencionalmente información personal de menores. Dado que el contenido se escribe y conserva localmente, padres, madres o tutores deberían supervisar su uso cuando corresponda.

10. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones, los servicios, los permisos o las prácticas de la aplicación. La fecha de actualización se mostrará de forma visible al comienzo de esta página.

11. Contacto

Para consultas sobre esta política, escribe a angular.apps14@gmail.com.
